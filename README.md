# Tryps Rideshare

A modern SwiftUI rideshare app prototype. Compare ride options, enter pickup and
destination details, request a trip, and review saved bookings in Activity.
Bookings are stored locally with SwiftData.

## Run

Open `TrypsRideshare.xcodeproj` in Xcode 15 or later, select an iPhone simulator,
and run the **TrypsRideshare** scheme. The app targets iOS 17 and later.

The map is a styled route preview; live maps, driver dispatch, payments, and
account services are not connected.
